# תקן תפריט A&I (ai-menu)

מקור מלא: https://github.com/Anat1969/AppOfApp-GH/blob/main/docs/ai-menu-standard.md
(הסיכום להלן נשלף מהמקור. לפני מימוש, להעתיק את המסמך המלא לכאן ולוודא שאין סתירות.)

## עיקרי התקן
- כפתור לוגו אחד בסרגל העליון, עם תווית "אד' ענת שטיבלמן A&I".
- פעולות עריכה ופיתוח בתוך הכפתור בלבד: מצב עריכה, הוספה, מחיקה, שינוי ניסוח, חיבור או ניתוק מכשיר עריכה, העתקת קישור, שיחת פיתוח, פרויקט מחקר, והתקנת האפליקציה.
- בסרגל: רק שם האפליקציה (מקשר לדף הבית), ניווט וחיפוש תוכן, והכפתור.
- מימוש: סקריפט משותף `ai-menu.js` שמתארח באפליקציית ההורה, ורכיב `<ai-menu>`. פעולות העריכה מועברות דרך מאפיין `menu.items`.
- לאתרים בלי סרגל עליון: וריאנט עם מאפייני data.
- רכיב React קיים בריפו של התקן.
- שער שחרור: כל בדיקת Playwright מאשרת שהכפתור נראה ושאין כפתורי פיתוח רופפים בסרגל.
- אפליקציות של עיריית אשדוד: לוגו עירוני דרך מאפיין `brand`. בכל בנייה לשאול למי שייכת האפליקציה ולרשום את התשובה ב-CLAUDE.md.

## מצב נוכחי של אניגרם (28.10.2026)
- הסרגל משתמש ב-`<ai-menu>` המשותף, שנטען ב-index.html. הכפתור המותאם הוסר.
- בתפריט: העתקת קישור, שיחת הפיתוח, התקנת האפליקציה. פרויקט המחקר יתווסף כשענת תמסור קישור (מאפיין `research` ב-`src/App.jsx`).
- אין פעולות עריכה: האפליקציה סטטית, לכן אין `menu.items`.
- שער התקן נבדק ב-`tests/e2e.cjs`.
