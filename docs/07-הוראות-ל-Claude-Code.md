# הוראות ל-Claude Code

## הפעלה ראשונה
1. פתחי את הריפו בטרמינל: `git clone https://github.com/Anat1969/AniGram-GH.git` ואז `cd AniGram-GH`.
2. הרצי: `uipro init --ai claude`.
3. הרצי: `npm install` ואז `npm run build`. אם הבנייה ירוקה, המצב תקין.
4. פתחי את Claude Code בתיקייה הזו.

## פרומפט פתיחה (להדבקה)
קראי קודם את CLAUDE.md ואת כל הקבצים בתיקיית docs. אחר כך:
1. סכמי במשפט אחד מה אני רוצה לעשות.
2. לפני כל שינוי קוד: בדקי את המצב הנוכחי, והציעי תוכנית קצרה.
3. עבדי לפי docs/03-עקרונות-בנייה.md.
4. אחרי שינוי: `npm run build` חייב להיות ירוק. לבדוק את הכפתורים.
5. בסיום: מה עשית, מה נבדק ומה לא, ומה הצעד הבא.

## משימות פתוחות לפי סדר עדיפות
1. בוצע: `<ai-menu>` לפי docs/06-תקן-תפריט-AI.md, עם קישור לשיחת הפיתוח.
2. פתוח: קישור לפרויקט המחקר (ענת תמסור את הכתובת).
3. בוצע: בדיקת כל הכפתורים בנייד ובדסקטופ (`tests/e2e.cjs`).
4. לאמת את התיאורים מול 9types.co.il ולהחליף את התיאורים בהתאם.

## כללי זהירות
- אסור להעתיק טקסט מהאתר של המרכז.
- אסור לתייג אדם בטיפוס, או לקשר טיפוס להפרעה נפשית או למצב רפואי.
- אסור לדחוף ישירות ל-main לפני שהבנייה ירוקה.
- כל תיקון של ענת נכנס ל-CLAUDE.md.
