# אניגרם

אפליקציית ידע חזותית על שיטת האניאגרם: דיאגרמה חיה, סיפור בגלילה, מפה אינטראקטיבית, השוואה בין טיפוסים ומפת מקורות. ראו docs/08-שכבה-חווייתית.md.

## הרצה מקומית

```
npm install
npm run dev
```

## בנייה

```
npm run build
```

## מקורות ותוכן

- שמות הטיפוסים לפי המרכז הישראלי לאניאגרם: https://9types.co.il/9types/
- התיאורים נכתבו במילים שלנו כסיכום ידע כללי, ומסומנים "ממתין לאימות מול המקור".

## הגבלות

- האפליקציה אינה מאבחנת ואינה קובעת טיפוס לאדם.
- האניאגרם אינו כלי מאומת מבחינה פסיכומטרית; ראו עמוד "על השיטה".
